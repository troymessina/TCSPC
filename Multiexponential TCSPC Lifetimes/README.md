# Multiexponential TCSPC Lifetimes
This code fits fluorescence lifetime data with an arbitrary number of exponential functions and an instrument response convolution. There are two versions of the same example. One is a self-contained Jupyter notebook (TCSPC_Lifetimes.ipynb). The other is a Jupyter notebook (TCSPC_Example.ipynb) that calls the library tcspc_lifetime.py. Data and instrument responses are included. The notebooks walk users through use of the code using the data and instrument responses. There are instructions for loading Becker-Hickl ascii or sdt files and PicoQuant ptu files.
